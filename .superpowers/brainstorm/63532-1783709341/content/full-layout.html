A · Focused accordion

Only the current set is expanded; done sets collapse to a ✓ header, upcoming sets collapse to a tappable header you can open to peek. Least scrolling, most "where am I" clarity.

B · Always-visible list

Every exercise for every set is on the page in order, like a paper checklist. Current set gets the accent ring; done sets dim with strikethrough. More scrolling, nothing hidden.
