How should a repeated set be checked off?

Your workouts are supersets/circuits done for several rounds. This is the core interaction decision — everything else builds on it. Example below: Superset 1 — Sumo squat + Alternating reverse fly, 3 rounds. Tap the option that matches how you'd want people to track it.

A · Round dots per exercise

Each exercise shows a dot per round. Tap a dot each time you finish that round. Exercise is done when all dots fill; the set is done when every dot is filled. Compact, matches "cycle the superset 3×."

B · One checkbox per exercise

Rounds are shown as a label only ("×3 rounds"). One checkbox per exercise — tick it once you've done all the rounds. Simplest and shortest list, but no per-round tracking.

C · A checkbox for every round

Each round is spelled out with its own checkboxes (Round 1, Round 2, Round 3). Most explicit and granular — closest to the current step-through — but the longest list to scroll.

You can select more than one if you like a hybrid, or just tell me in the terminal. I'm also happy to hear "none of these — here's what I picture."
