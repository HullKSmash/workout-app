# Exercise Database Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a local SQLite database as the single source of truth for exercises, seeded from current data, and generate the app's workout `.js` files from it.

**Architecture:** Text `.sql` files (`data/schema.sql` + `data/data.sql`) are the git-tracked canonical form. A build script produces a queryable `data/exercises.db` (gitignored) via the built-in `node:sqlite` module. A one-time, tooled **seed** imports the exercise CSV + parses existing workout `.js` files, reconciles exercise names, and emits `data/data.sql`. An **exporter** queries app-bound workouts from the DB and regenerates `workouts/<slug>.js` directly (no CSV hop).

**Tech Stack:** Node 24 (`node:sqlite`, `node:test`, `node:assert` — all built-in, zero new deps), `sqlite3` CLI 3.51 for ad-hoc queries. ESM (`"type": "module"`).

**Schema refinements beyond the spec sketch:** the `workouts` table adds `slug TEXT NOT NULL UNIQUE` (the target `.js` filename), and `workout_exercises` adds `phase_pos INTEGER` (explicit phase ordering so hand-edits to `data.sql` don't rely on row order). These are the export ordering/target keys.

**Two phases:** Tasks 1–7 build the source of truth (DB + seed). Tasks 8–10 build and run the app exporter. Tasks 7, 9, and 10 need the real exercise CSV export from the spreadsheet.

  name        TEXT NOT NULL,
  slug        TEXT NOT NULL UNIQUE,  -- target workouts/<slug>.js filename

  difficulty  TEXT,                  -- easier | moderate | harder
  description TEXT
);

CREATE TABLE workout_exercises (
  workout_id   INTEGER NOT NULL REFERENCES workouts(id),
  exercise_id  INTEGER NOT NULL REFERENCES exercises(id),
  phase        TEXT NOT NULL,     -- 'Warm Up', 'Circuit 1', ...
  phase_pos    INTEGER NOT NULL,  -- phase order within the workout
  circuit_pos  INTEGER NOT NULL,  -- circuit order within the phase
  rounds       INTEGER NOT NULL,  -- circuit repeatCount
  position     INTEGER NOT NULL,  -- exercise order within the circuit

  tips         TEXT               -- optional per-workout override; NULL = use exercise.tips
);

import { readFileSync, existsSync, rmSync } from "node:fs";
import { DatabaseSync } from "node:sqlite";

/**
 * Builds a fresh SQLite database from a schema file and optional data file.
 * Deletes any existing db at dbPath first so CREATE TABLE never collides.
 * @param {{schemaPath: string, dataPath?: string, dbPath: string}} opts
 * @returns {string} dbPath
 */
export function buildDb({ schemaPath, dataPath, dbPath }) {
  if (existsSync(dbPath)) rmSync(dbPath);
  const db = new DatabaseSync(dbPath);
  db.exec(readFileSync(schemaPath, "utf8"));
  if (dataPath && existsSync(dataPath)) db.exec(readFileSync(dataPath, "utf8"));
  db.close();
  return dbPath;
}
```

/**
 * Tokenizes CSV text into rows of string fields.
 * Handles quoted fields, escaped quotes (""), and newlines inside quotes.
 * @param {string} text
 * @returns {string[][]}
 */
export function parseCsv(text) {
  const s = text.replace(/\r\n/g, "\n").replace(/\r/g, "\n");
  const rows = [];
  let row = [];
  let field = "";
  let inQuotes = false;
  for (let i = 0; i < s.length; i++) {
    const ch = s[i];
    if (inQuotes) {
      if (ch === '"') {
        if (s[i + 1] === '"') { field += '"'; i++; }
        else inQuotes = false;
      } else field += ch;
    } else if (ch === '"') {
      inQuotes = true;
    } else if (ch === ",") {
      row.push(field);
      field = "";
    } else if (ch === "\n") {
      row.push(field);
      rows.push(row);
      row = [];
      field = "";
    } else {
      field += ch;
    }
  }
  if (field !== "" || row.length) {
    row.push(field);
    rows.push(row);
  }
  return rows;
}

/**
 * Parses an exercise CSV (headers: Name, Tips, Video) into records.
 * @param {string} text
 * @returns {{name: string, tips: string, video: string}[]}
 */
export function parseExercisesCsv(text) {
  const rows = parseCsv(text).filter((r) => r.some((c) => c.trim() !== ""));
  if (rows.length === 0) return [];
  const header = rows[0].map((h) => h.trim().toLowerCase());
  const iName = header.indexOf("name");
  const iTips = header.indexOf("tips");
  const iVideo = header.indexOf("video");
  return rows
    .slice(1)
    .map((r) => ({
      name: (r[iName] ?? "").trim(),
      tips: iTips >= 0 ? (r[iTips] ?? "").trim() : "",
      video: iVideo >= 0 ? (r[iVideo] ?? "").trim() : "",
    }))
    .filter((e) => e.name !== "");
}
```

/**
 * Normalizes an exercise name for fuzzy comparison:
 * lowercase, non-alphanumerics → single spaces, trimmed.
 * @param {string} s
 * @returns {string}
 */
export function normalizeName(s) {
  return s
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, " ")
    .trim();
}

/**
 * Reconciles workout-referenced exercise names against the canonical set.
 * @param {{id: number, name: string}[]} canonical
 * @param {string[]} referenced  names referenced by workouts (may repeat)
 * @param {Record<string,string>} aliases  referencedName -> canonicalName
 * @returns {{
 *   exact: string[],
 *   near: {referenced: string, canonical: string}[],
 *   unmatched: string[],
 *   resolved: Map<string, {id: number, name: string}>
 * }}
 */
export function reconcile(canonical, referenced, aliases = {}) {
  const byExact = new Map();
  const byNorm = new Map();
  for (const ex of canonical) {
    byExact.set(ex.name, ex);
    byNorm.set(normalizeName(ex.name), ex);
  }

  const exact = [];
  const near = [];
  const unmatched = [];
  const resolved = new Map();

  const seen = new Set();
  for (const name of referenced) {
    if (seen.has(name)) continue;
    seen.add(name);

    if (aliases[name]) {
      const target =
        byExact.get(aliases[name]) || byNorm.get(normalizeName(aliases[name]));
      if (target) {
        resolved.set(name, target);
        continue;
      }
    }

    if (byExact.has(name)) {
      exact.push(name);
      resolved.set(name, byExact.get(name));
    } else if (byNorm.has(normalizeName(name))) {
      const target = byNorm.get(normalizeName(name));
      near.push({ referenced: name, canonical: target.name });
      resolved.set(name, target);
    } else {
      unmatched.push(name);
    }
  }

  return { exact, near, unmatched, resolved };
}
```

/**
 * Flattens a workout object into a metadata record + ordered instance rows.
 * repCount is stringified (rep_count is TEXT; Rest seconds become e.g. "30").
 * @param {string} slug  filename stem, e.g. "rider-mini-circuits-2"
 * @param {object} w     workout object (default export of a workouts/*.js file)
 */
export function flattenWorkout(slug, w) {
  const workout = {
    slug,
    name: w.name,
    audiences: (w.audiences ?? []).join(","),
    difficulty: w.difficulty ?? "",
    description: w.description ?? "",
  };

  const instances = [];
  w.phases.forEach((phase, phasePos) => {
    phase.circuits.forEach((circuit, circuitPos) => {
      circuit.exercises.forEach((ex, position) => {
        instances.push({
          phase: phase.name,
          phasePos,
          circuitPos,
          rounds: circuit.repeatCount,
          position,
          exerciseName: ex.name,
          repCount: String(ex.repCount),
          tips: ex.tips ?? null,
        });
      });
    });
  });

  return { workout, instances };
}
```

```js
function sqlStr(v) {
  return v == null ? "NULL" : `'${String(v).replace(/'/g, "''")}'`;
}
function sqlNum(v) {
  return v == null ? "NULL" : String(v);
}

/**
 * Renders the canonical data.sql text from a resolved model.
 * @param {{
 *   exercises: {id:number,name:string,tips:?string,video_url:?string}[],
 *   workouts: {id:number,name:string,slug:string,audiences:?string,difficulty:?string,description:?string}[],
 *   joins: {workout_id:number,exercise_id:number,phase:string,phase_pos:number,circuit_pos:number,rounds:number,position:number,rep_count:string,tips:?string}[]
 * }} model
 * @returns {string}
 */
export function emitDataSql({ exercises, workouts, joins }) {
  const lines = [
    "-- Generated by scripts/seed. Canonical source of truth; edit by hand thereafter.",
    "BEGIN;",
  ];
  for (const e of exercises) {
    lines.push(
      `INSERT INTO exercises (id, name, tips, video_url) VALUES (${sqlNum(e.id)}, ${sqlStr(e.name)}, ${sqlStr(e.tips)}, ${sqlStr(e.video_url)});`,
    );
  }
  for (const w of workouts) {
    lines.push(
      `INSERT INTO workouts (id, name, slug, audiences, difficulty, description) VALUES (${sqlNum(w.id)}, ${sqlStr(w.name)}, ${sqlStr(w.slug)}, ${sqlStr(w.audiences)}, ${sqlStr(w.difficulty)}, ${sqlStr(w.description)});`,
    );
  }
  for (const j of joins) {
    lines.push(
      `INSERT INTO workout_exercises (workout_id, exercise_id, phase, phase_pos, circuit_pos, rounds, position, rep_count, tips) VALUES (${sqlNum(j.workout_id)}, ${sqlNum(j.exercise_id)}, ${sqlStr(j.phase)}, ${sqlNum(j.phase_pos)}, ${sqlNum(j.circuit_pos)}, ${sqlNum(j.rounds)}, ${sqlNum(j.position)}, ${sqlStr(j.rep_count)}, ${sqlStr(j.tips)});`,
    );
  }
  lines.push("COMMIT;");
  return lines.join("\n") + "\n";
}
```

```js
import { parseExercisesCsv } from "./parse-exercises-csv.mjs";
import { reconcile } from "./reconcile.mjs";
import { flattenWorkout } from "./flatten-workout.mjs";
import { emitDataSql } from "./emit-data-sql.mjs";

/**
 * Pure seed core. Returns a reconciliation report and, if every referenced
 * exercise resolved, the canonical data.sql text (else dataSql is null).
 * @param {{
 *   exercisesCsv: string,
 *   workouts: {slug: string, obj: object}[],
 *   aliases: Record<string,string>
 * }} input
 * @returns {{report: {exact: string[], near: object[], unmatched: string[]}, dataSql: ?string}}
 */
export function runSeed({ exercisesCsv, workouts, aliases }) {
  const records = parseExercisesCsv(exercisesCsv);
  const exercises = records.map((e, i) => ({
    id: i + 1,
    name: e.name,
    tips: e.tips || null,
    video_url: e.video || null,
  }));
  if (!exercises.some((e) => e.name === "Rest")) {
    exercises.push({ id: exercises.length + 1, name: "Rest", tips: null, video_url: null });
  }

  const flattened = workouts.map(({ slug, obj }) => flattenWorkout(slug, obj));
  const referenced = flattened.flatMap((f) => f.instances.map((i) => i.exerciseName));
  const rec = reconcile(exercises, referenced, aliases);

  const report = { exact: rec.exact, near: rec.near, unmatched: rec.unmatched };
  if (rec.unmatched.length > 0) {
    return { report, dataSql: null };
  }

  const workoutRows = flattened.map(({ workout }, i) => ({ id: i + 1, ...workout }));
  const joins = [];
  flattened.forEach(({ instances }, wi) => {
    for (const inst of instances) {
      const ex = rec.resolved.get(inst.exerciseName);
      const canonicalTip = ex.tips ?? null;
      const instTip = inst.tips ?? null;
      const tipOverride = instTip !== canonicalTip ? instTip : null;
      joins.push({
        workout_id: wi + 1,
        exercise_id: ex.id,
        phase: inst.phase,
        phase_pos: inst.phasePos,
        circuit_pos: inst.circuitPos,
        rounds: inst.rounds,
        position: inst.position,
        rep_count: inst.repCount,
        tips: tipOverride,
      });
    }
  });

  const dataSql = emitDataSql({ exercises, workouts: workoutRows, joins });
  return { report, dataSql };
}
```

```js
/**
 * Rebuilds the app's nested workout object from DB rows.
 * Ordering is deterministic: (phase_pos, circuit_pos, position).
 * Tips resolve as override (join.tips) else the exercise default. Rest gets no tip
 * and a numeric repCount.
 * @param {object} workoutRow  a row from the workouts table
 * @param {object[]} joins     workout_exercises rows for this workout
 * @param {Map<number, {id:number,name:string,tips:?string}>} exercisesById
 * @returns {object} app workout object
 */
export function reshapeWorkout(workoutRow, joins, exercisesById) {
  const sorted = [...joins].sort(
    (a, b) =>
      a.phase_pos - b.phase_pos ||
      a.circuit_pos - b.circuit_pos ||
      a.position - b.position,
  );

  const phases = [];
  const phaseByPos = new Map();
  const circuitByKey = new Map();

  for (const j of sorted) {
    let phase = phaseByPos.get(j.phase_pos);
    if (!phase) {
      phase = { name: j.phase, circuits: [] };
      phaseByPos.set(j.phase_pos, phase);
      phases.push(phase);
    }
    const ck = `${j.phase_pos}:${j.circuit_pos}`;
    let circuit = circuitByKey.get(ck);
    if (!circuit) {
      circuit = { repeatCount: j.rounds, exercises: [] };
      circuitByKey.set(ck, circuit);
      phase.circuits.push(circuit);
    }

    const ex = exercisesById.get(j.exercise_id);
    const isRest = ex.name === "Rest";
    const exercise = { name: ex.name, repCount: isRest ? Number(j.rep_count) : j.rep_count };
    const tip = j.tips ?? ex.tips;
    if (tip && !isRest) exercise.tips = tip;
    circuit.exercises.push(exercise);
  }

  return {
    name: workoutRow.name,
    audiences: workoutRow.audiences ? workoutRow.audiences.split(",") : [],
    difficulty: workoutRow.difficulty ?? "",
    description: workoutRow.description ?? "",
    phases,
  };
}

/**
 * Renders a workout object as a workouts/*.js file body.
 * Matches the existing format: `export default ` + 2-space JSON + `;`.
 * @param {object} obj
 * @returns {string}
 */
export function renderWorkoutJs(obj) {
  return `export default ${JSON.stringify(obj, null, 2)};\n`;
}
```

## Notes for the implementer

- **Node `node:sqlite` emits an `ExperimentalWarning`** on first use. This is expected; it does not affect correctness. Do not suppress warnings globally.
- **The seed is intentionally two-pass.** Never auto-create exercises from unmatched workout names — that reintroduces the duplication this project exists to eliminate. Unmatched names must be resolved by a human via `scripts/aliases.json`, a source fix, or a spreadsheet addition.
- **The exporter never touches `workouts/index.js`.** It only writes workout `.js` content files. Which workouts are active/hidden remains a manual `index.js` decision.
- **`data/data.sql` is canonical after seeding.** Future exercise/workout edits are hand-edits to `data/data.sql` (or re-runs of the seed), followed by `npm run db:build` and `npm run db:export`.
